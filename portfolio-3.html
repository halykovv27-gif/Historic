Веб-сайт қалай жасалады?

Сайтты үй салуға теңеуге болады:

HTMLҚабырға мен бөлмелерҚұрылым мен мазмұн
CSSСыртқы әрлеу, түс, жиһазКөрініс пен дизайн
GitHubҮйдің мекенжайы мен құжатыСақтау және жариялау

HTML дегеніміз не?

  • HyperText Markup Language — беттің белгілеу тілі.
  • Бетте не бар екенін айтады: тақырып, мәтін, сурет, сілтеме.
  • Бағдарламалау тілі емес, белгілеу (тегтер) тілі.
  • Файл кеңейтімі: .html. Кез келген браузерде ашылады.

HTML: негізгі тегтер

  • <h1> — тақырып
  • <p> — абзац
  • <a> — сілтеме
  • <img> — сурет
  • <section> — бөлім
<h1>Сәлем, мен Ақанмын!</h1>
<p>Мен география
мұғалімі боламын.</p>
<a href="#works">
  Жұмыстарым
</a>

CSS дегеніміз не?

  • Cascading Style Sheets — стильдер кестесі.
  • Түс, қаріп, өлшем, орналасуды басқарады.
  • Бір ережені бүкіл сайтқа қолдануға болады.
  • Телефон мен компьютерге бейімдеуге мүмкіндік береді.

CSS: код үлгісі

h1 {
  color: #2b1d5c;
  font-size: 48px;
}
.btn {
  background: #6fe3c1;
  border-radius: 999px;
}
@media (max-width: 560px) {
  h1 { font-size: 32px; }
}
  • Селектор — қай элементке
  • Қасиет — нені өзгертеміз
  • Мән — қандай болсын
  • @media — телефонға бейімдеу

GitHub дегеніміз не?

  • Жоба кодын сақтайтын онлайн платформа.
  • Репозиторий — жоба папкасы.
  • Commit — өзгерістерді сақтау, тарихы бар.
  • Командамен бірге жұмыс істеуге және кодты ашық бөлісуге болады.

GitHub Pages: сайтты жариялау

  1. github.com-да тіркеліп, аты.github.io репозиторийін жасаңыз.
  2. Add file → Upload files: index.html жүктеңіз.
  3. Settings → Pages: main тармағын таңдаңыз.
  4. 1–2 минуттан кейін сайт https://аты.github.io мекенжайында ашылады.

Жасанды интеллект және этикалық нормалар

13.2 · СӨЖ · Эссе (№2) · 0 сөз

Жасанды интеллект (ЖИ) бүгінде біздің өміріміздің ажырамас бөлігіне айналды. Ол мәтін жазады, есеп шығарады, аударма жасайды, сурет салады және сұрақтарға секундтар ішінде жауап береді. Мұндай құрал мектеп оқушыларына да қолжетімді болды, сондықтан қоғамда маңызды сұрақ туындады: ЖИ мүмкіндіктерін төменгі сыныптардан бастап оқыту керек пе, әлде оқушыларды құралды сауатты пайдалануға баулу маңыздырақ па?

Бір топ маман ЖИ-ді бастауыш сыныптан бастап үйрету қажет деп есептейді. Олардың пікірінше, бала технологиямен ерте танысса, оны қауіпсіз әрі тиімді қолдануды тез меңгереді. Қазіргі ұрпақ цифрлық ортада өседі, ал болашақта ЖИ-мен жұмыс істей білу еңбек нарығындағы негізгі дағдылардың біріне айналады. Ерте танысу баланың қызығушылығын арттырып, жаңа кәсіптерге жол ашады.

Екінші көзқарас бойынша, ең алдымен құралды сауатты пайдалануға баулу керек. Егер оқушы дайын жауапты ойланбай көшіре берсе, ол өз бетінше ойлау, талдау және жазу дағдысынан айырылады. ЖИ қате немесе ойдан шығарылған ақпарат бере алады, сондай-ақ жеке деректердің құпиялығына қауіп төндіруі мүмкін. Сондықтан академиялық адалдық, авторлық құқық және деректерді қорғау ережелерін ерте түсіндірген дұрыс.

Сонымен қатар ата-аналар мен мектеп әкімшілігі де бұл үдерістен тыс қалмауы керек. Оқушыға ЖИ-ді қай жерде пайдалануға болатынын, қай жерде болмайтынын айқын түсіндіретін мектеп ережелері қажет. Мұндай ережелер сенімді орта қалыптастырып, балаға технологияны жасырынбай, ашық әрі адал қолдануға мүмкіндік береді.

Менің ойымша, бұл екі көзқарас бір-біріне қарсы емес, керісінше бір-бірін толықтырады. ЖИ-ді оқыту мен этикалық нормаларды үйрету қатар жүруі тиіс. Бала құралдың қалай жұмыс істейтінін білсе ғана, оның шектеулерін де түсінеді. Мұғалімнің рөлі де аса маңызды: ол тапсырманы ЖИ орындап бере алмайтындай етіп құрып, оқушыны ойлануға, дерек көздерін тексеруге бағыттауы керек. Қорыта айтқанда, ЖИ — көмекші құрал, ал нәтижеге жауапкершілік әрқашан адамның өзінде қалуы тиіс.
